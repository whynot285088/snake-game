# 🐍 Snake Game

Python과 JavaScript로 만든 스네이크 게임 시리즈입니다.  
Google Colab에서 바로 실행 가능하며, 버전별로 기능을 추가하며 개발했습니다.

---

## 🎮 현재 버전: v4 - 최종 완성판

### 실행 방법
1. `snake_game.ipynb` 파일을 Google Colab에서 열기
2. 셀을 순서대로 실행 (단축키: `Shift + Enter`)
3. 마지막 셀 실행 후 게임 시작

### 조작법
| 키 | 동작 |
|-----|------|
| ↑↓←→ | 방향 전환 |
| R | 게임 재시작 |
| Q | 슬로우 포션 사용 |

### v4 기능
- 먹이를 먹을 때마다 장애물 랜덤 생성
- 코인 시스템 (점수 ÷ 10 = 코인)
- 상점: 목숨 구매 / 슬로우 포션 구매 (50🪙)
- 슬로우 포션: Q키 또는 버튼으로 사용, 8초간 속도 감소, 뱀 보라색으로 변함
- 도전과제 8종 (달성 시 코인 보상)
- 게임오버 오버레이에서 상점/도전과제 접근
