# 🐍 Snake Game

Python과 JavaScript로 만든 스네이크 게임 시리즈입니다.  
Google Colab에서 바로 실행 가능하며, 버전별로 기능을 추가하며 개발했습니다.

---

## 🎮 현재 버전: v1 - 기본 버전

### 실행 방법
1. `snake_game.ipynb` 파일을 Google Colab에서 열기
2. 셀을 순서대로 실행 (단축키: `Shift + Enter`)
3. 마지막 셀 실행 후 게임 시작

### 조작법
| 키 | 동작 |
|-----|------|
| ↑↓←→ | 방향 전환 |
| R | 게임 재시작 |

### v1 기능
- 18×18 그리드 기본 스네이크 게임
- 점수 / 레벨 / 최고점수 표시
- 레벨업마다 속도 증가
- 최고점수 브라우저 저장
