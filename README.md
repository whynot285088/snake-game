# 🐍 Snake Game

Python과 JavaScript로 만든 스네이크 게임 시리즈입니다.  
Google Colab에서 바로 실행 가능하며, 버전별로 기능을 추가하며 개발했습니다.

---

## 🎮 현재 버전: v2 - 개선판

### 실행 방법
1. `snake_game.ipynb` 파일을 Google Colab에서 열기
2. 셀을 순서대로 실행 (단축키: `Shift + Enter`)
3. 마지막 셀 실행 후 게임 시작

### 조작법
| 키 | 동작 |
|-----|------|
| ↑↓←→ | 방향 전환 |
| R | 게임 재시작 |

### v2 기능
- 25×25 그리드로 확장
- 속도 조정: 200ms 시작, 레벨당 5ms 감소, 최소 100ms
- 100점마다 레벨업
- 둥근 뱀 세그먼트, 색상 그라데이션
- 캔버스 위에 게임오버 오버레이 표시
